# Folien Tag 1

Die Foliensätze von Tag 1 zum Nachlesen. Im Browser öffnen, am besten mit
**„Tag 1 · Übersicht.html“**: Ein Klick auf eine Karte öffnet den Foliensatz dieser Sitzung.

- Blättern mit den Pfeiltasten, `Esc` zeigt alle Folien einer Sitzung.
- Screenshots lassen sich anklicken und vergrößern.
- Die Folien funktionieren ohne Internet. Der Ordner `gemeinsam/` gehört dazu (Folien-Software und Schriften),
  bitte mitkopieren.
- PDF: im Browser „Drucken“, „Als PDF speichern“ (Ränder „Keine“, Hintergrundgrafiken an), oder `Tag 1 · Folien.pdf`.

Die Folien des Einführungsvortrags sind nicht Teil dieses Ordners.
