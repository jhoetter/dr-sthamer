MCP ist ein Stecker-Standard für KI

Statt für jedes System eine eigene Verbindung zu bauen, spricht Claude eine gemeinsame Sprache.

1

Ohne Standard: jede KI braucht für jedes System eine eigene Verbindung

2

Mit MCP: ein System bietet seine Funktionen einmal an, jede passende KI-App kann sie nutzen

3

Das Bild dazu: USB-C für KI, ein Stecker für viele Geräte

4

MCP ist ein offener Standard; Anthropic hat ihn 2024 veröffentlicht, viele Anbieter nutzen ihn

„Heute habt Ihr Claude CSV-Dateien gegeben. Mit MCP fragt Claude das System selbst.“

Ein MCP-Server bietet Werkzeuge mit Beschreibung an

Claude liest die Beschreibungen, wählt ein Werkzeug und fragt Euch, bevor es handelt.

Client
Die Claude-App auf Eurem Rechner. Sie verbindet sich mit einem oder mehreren Servern.
→
Server
Ein kleines Programm vor einem System, etwa dem ERP. Es bietet Werkzeuge an.
→
Werkzeug
Eine Funktion mit Namen und Beschreibung, z. B. „Aufträge eines Kunden lesen“.
→
Freigabe
Bevor Claude ein Werkzeug nutzt, fragt es. Lesen ist etwas anderes als Schreiben.

Input · Was ist MCP?

Jeder Anschluss braucht klare Grenzen

MCP öffnet Systeme für die KI; damit wachsen Nutzen und Risiko zugleich.

Rechte
Nur so viel Zugriff wie nötig: lesen statt schreiben, ein Ordner statt das ganze Laufwerk.
Daten
Was ein Werkzeug liefert, geht zur Verarbeitung an das Modell. Vertrauliches bewusst ausschließen.
Herkunft
Nur Server aus vertrauenswürdiger Quelle; Texte von außen können versteckte Anweisungen enthalten.
Morgen

An Tag 2 arbeitet Johannes Hötter mit solchen Anschlüssen. Heute reicht: wissen, was MCP ist und wo die Grenzen liegen.
