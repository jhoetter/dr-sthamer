# Workshop-Folien: ITMP × Dr. Sthamer

`ITMP × Dr. Sthamer — Workshop-Folien.html` im Browser öffnen: eigenständige Datei (reveal.js, Schriften und Logos eingebettet), läuft ohne Internet. Pfeiltasten blättern, **F** Vollbild, **ESC** alle Folien, `?print-pdf` an die Adresse hängen für PDF (Drucken, Hintergrundgrafiken an).

Elf Folien für den zweitägigen Workshop: Titel, Team, Agenda (zwei Tage, Tag 1, Tag 2), Fallstudie Dr. Sthamer, These, Kontrollen, Prompt-Muster, Drill 1 von Tag 2, Schluss.

## Herkunft

Die Gestaltung stammt aus der Vorlage von Falk Uebernickel (`github.com/falkue/ai-studio-foliensatz`, Comicstil «Golden Age»). Hier angepasst: ITMP-Logo statt Universitätslogo, Inhalte für Dr. Sthamer statt Pfefferminzia, dritte Karte mit Dr. Marc Kohler auf der Team-Folie (Comicfigur `assets/figur/marc-sakko-*.svg`, im Stil der Figuren von Falk und Johannes).

## Noch zu prüfen

Alles, was in der Datei in eckigen Klammern steht: Ort, Zeiten, Datum. Das ITMP-Logo liegt nur als kleines Bild (200 × 200 Pixel) vor; ein SVG oder größeres PNG wäre schärfer. Die Comicfigur von Falk auf der Folie «Kontrollen» stammt aus der Vorlage.

reveal.js 5.2.0 (MIT). Schriften Bangers, Barlow und JetBrains Mono (SIL Open Font License 1.1), eingebettet. Das Logo von Dr. Sthamer stammt aus `web/logo-sthamer.png`.
